# 01 · Accounts and the Claude app

**You do this part by hand.** About 30 minutes.

1. Create or sign in to: **GitHub** (free), a **Google account** (free), **Cloudflare** (free), **Calendly** (free).
2. Buy **Claude Pro** ($20/month, or $17/month billed yearly) at claude.com/pricing.
3. Install the Mac app from claude.com/download and sign in.
4. Open **Claude Code** in the app (or claude.ai/code) and start a **cloud** session.
5. When asked, connect **GitHub** and pick which repos Claude may use.

Then paste:

```text
Check my setup. Tell me which of these are done and what's missing:
Claude Code cloud session working, GitHub connected, a repo I can write to.
If I have no repo yet, tell me how to create a private repo called
"job-search" on github.com, and wait while I do it.
```
