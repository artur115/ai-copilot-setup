# 03 · Environments and keys

A cloud **environment** is a saved setup: which websites a session may reach (the network allowlist), environment variables and a setup script. **API keys** go through the secure credential form, never into chat.

```text
Explain my current cloud environment: network access, allowed hosts, and whether
it has a setup script. Then:
1. Suggest the smallest allowlist for a job-search repo (GitHub, Cloudflare,
   package registries, Google Fonts) and propose it. I'll approve it. Include
   LinkedIn (linkedin.com, www.linkedin.com, lnkd.in) and the public job-board
   APIs (boards-api.greenhouse.io, api.ashbyhq.com, api.lever.co,
   job-boards.greenhouse.io, jobs.ashbyhq.com, jobs.lever.co) so you can open
   job links I send and check companies' openings.
2. If any step later needs an API key, use the secure credential form. Never ask
   me to paste a key here.
3. Add a rule to this repo's CLAUDE.md: never write my email address or phone
   number into files or web requests unless I type it in the same message.
```
