# 11 · LinkedIn with Claude in Chrome

Cloud sessions can't reach your browser, so this runs **on your Mac** with the Claude in Chrome extension (paid plans).

**By hand:** Chrome Web Store → "Claude in Chrome" → Add to Chrome → pin it (puzzle icon) → sign in. To revoke site access later: extension settings → Site permissions.

Then, in the Claude in Chrome side panel on linkedin.com:

```text
Help me update my LinkedIn profile. Ask before each change and let me approve it:
1. Contact info → Website: set it to https://<yourname>.dev
2. Featured: add my resume PDF and my best project repo.
3. Job application settings (Jobs → Application settings): upload the new resume.
4. Suggest a headline and About section that match my site. Show me drafts
   first; don't save without my OK.
```
