# 05 · Knowledge graph (graphify)

Useful once a repo has more than a handful of files. graphify maps the code so Claude reads the map first and opens fewer files.

```text
Set up graphify (PyPI package graphifyy, repo Graphify-Labs/graphify) for this
repo: install it, run it on the repo, and commit graphify-out/ (but not its
cache). Add a line to CLAUDE.md telling you to read graphify-out/GRAPH_REPORT.md
before answering questions about the code. Then show me the three most
connected parts of the codebase and open graph.html for me to look at.
```
