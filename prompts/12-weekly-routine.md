# 12 · Weekly routine

A suggested starting point. Change it to fit you.

```text
Every Monday, help me plan the week's job search:
1. From my notes in SETUP-CHECKLIST.md and my Simplify tracker export, list
   applications older than 7 days with no reply, and draft short follow-ups
   (as Gmail drafts, never sent).
2. Suggest 10 roles to look at this week that fit my target title and location.
3. Pick one small improvement to a portfolio project and open a task for it.
4. Summarize last week: applications sent, replies, calls booked.
```

You can make this a scheduled task in Claude Code so it runs every Monday morning.
