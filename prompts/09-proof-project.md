# 09 · A proof project for your strongest claim

```text
Use the proof-project skill. My resume line is:
"<paste the bullet, with its number>"
Help me build a small public GitHub project that shows the method behind it,
using synthetic data only (nothing from my employer). It should run on a laptop,
have tests and CI, and a README that opens with the result and how to reproduce
it. Then add it to my resume's Projects section and my site.
```

My example: [social-commerce-ltv](https://github.com/artur115/social-commerce-ltv) backs up "+38% LTV from social channels", with 18 tests and GitHub Actions CI.
