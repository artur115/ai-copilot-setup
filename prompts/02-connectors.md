# 02 · Connectors

Connectors (also called MCP servers) let Claude work inside your apps. In the Claude app: **Settings → Connectors → pick one → Connect → sign in → Allow**.

Start with: GitHub, Gmail, Google Calendar, Google Drive (Docs, Sheets, Slides), Cloudflare, Calendly. Add Figma, Supabase or Slack later if you need them.

```text
List the connectors you can use in this session. For each one, do one small
read-only check that it works (for example: list my 3 most recent Drive files,
my next calendar event, my GitHub repos). Don't send, create or delete anything.
Then tell me which useful connectors I haven't connected yet and why I'd want them.
```
